MEUS JOGOS - CÓDIGOS DE TRAPAÇA POR CONSOLE
Feito para o app Meus Jogos Retrô (EmulatorJS).
Fonte dos códigos: almarsguides.com (versões USA, salvo quando indicado).

==============================================================================
COMO USAR NO APP
==============================================================================
1) Abra o jogo no app (MeusJogosRetro.html, pelo servidor local).
2) Mova o mouse ou toque na tela do jogo para aparecer a barra de botões.
3) Toque em "Trapaças" > "Adicionar Trapaça".
4) Cole o código em "Código", escreva um nome em "Descrição" e toque em "Enviar".
5) Deixe a trapaça marcada na lista. Para desligar, desmarque (alguns códigos só
   desligam reiniciando o jogo).

- Código de várias linhas: junte as linhas com o sinal + (ex.: CODIGO1+CODIGO2),
  ou cadastre uma linha por vez.
- As trapaças ficam salvas por jogo, neste navegador.
- Se um código não fizer efeito: confira se é do console certo, da região USA e
  se o formato está certo. Teste o código alternativo, quando houver.
- Com trapaça ativa, evite salvar o jogo: pode gravar valores alterados.

FORMATO ACEITO POR CONSOLE
==============================================================================
Nintendo 64 ........ GameShark, 12 caracteres (8 + 4)      ex.: 8033B21D 0064
Super Nintendo ..... Game Genie ou Pro Action Replay (PAR)  ex.: C222-D4DD / 7E0DBE63
Mega Drive ......... Game Genie ou Action Replay            ex.: AL7T-AA6L / FFEF82:000A
Master System ...... Game Genie ou Action Replay
NES ................ Game Genie (6 ou 8 letras) ou hexadecimal ex.: SXUGTPVG

Legenda: [GG] Game Genie   [PAR] Pro Action Replay   [AR] Action Replay   [GS] GameShark
